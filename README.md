# Funkin' Everywhere
<img alt="Our logo" src="docs/FE_Logo.png" />
Funkin' Everywhere is a Friday Night Funkin' fan project based on Scratch Everywhere! that allows you to play Friday Night Funkin on basically any 6th-8th generation handheld/console. This program is written in c++ and uses no generative AI outside of using it for fixing bugs if need be (I still hope to change this).
